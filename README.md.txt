# Indian Stock Market Analysis 📊

## 📌 Project Overview

This project analyzes Indian stock market data using Python, PostgreSQL, Google Sheets, and Power BI.

The objective is to understand stock performance, sector-wise returns, risk, and market trends through data analysis and interactive dashboards.

## 🛠️ Tools & Technologies

* Python
* PostgreSQL & pgAdmin
* Google Sheets / Excel
* Power BI
* SQL
* GitHub

## 📊 Key Analysis

* Total return analysis of companies
* Top 10 companies by total return
* Sector-wise performance analysis
* NIFTY 50 benchmark comparison
* Annualized volatility analysis
* Risk vs return analysis
* Average closing price trends

## 📈 Power BI Dashboard

The interactive dashboard includes:

* KPI cards
* Date, sector, and company filters
* Company return comparison
* Sector performance chart
* Closing price trend
* Risk vs return scatter chart

## 🎯 Project Objective

To develop practical data analytics skills by analyzing stock market data and presenting insights through SQL queries and interactive Power BI visualizations.
